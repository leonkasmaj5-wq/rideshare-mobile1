# Raporti i Javës 05

## Përshkrimi i Punës
Kemi ndërtuar panelin e menaxhimit të udhëtimeve me përditësimin e orarit dhe autorizimin nga GitHub.

## Prova 1
Kemi testuar përditësimin e orarit për udhëtimin ID 2. Udhëtimi me ID 2 u përditësua me sukses në orën 08:25 në bazën e të dhënave.

## Prova 2
Kemi provuar përditësimin e udhëtimit ID 1 pa autorizim. Udhëtimi me ID 1 u refuzua dhe ora mbeti e paprekur në 08:00.

## Prova 3
Kemi verifikuar hyrjen me GitHub dhe lejet. Hyrja me GitHub funksionon dhe lejet e panelit zbatohen saktë.
